# PickMe Taxi (Flutter, локальная база)

Такси на Яндекс.Картах. **Сервера нет**: все данные хранятся в SQLite прямо в телефоне.
Пассажир и водитель — это два аккаунта на одном устройстве (вход по email и паролю).
Розовое оформление и карта из навигатора сохранены.

## Как пользоваться (одно устройство)

1. Зарегистрируйте **пассажира** («Я пассажир») и **водителя** («Я водитель», с маркой и госномером авто).
2. Войдите пассажиром → постройте маршрут → «Заказать такси». Заказ сохранится в базе.
3. Выйдите (меню-аватар в левом верхнем углу → «Выйти») и войдите водителем.
4. Водитель: включите «На линии» → увидите заказ → «Принять» → «Я на месте» → «Начать поездку» → «Завершить».
5. Выйдите и войдите пассажиром: приложение откроет ваш заказ с актуальным статусом.

Заказ, принятый водителем, сохраняется между входами и перезапусками приложения.

## Что работает

- **Пассажир:** поиск адресов и организаций, клик по карте, промежуточные точки, пробки, цена, оплата
  (наличные / «картой (тест)»), ход поездки, отмена, закладки, история, «Дом/Работа» — у каждого аккаунта свои.
- **Водитель:** «На линии», список свободных заказов (ближайшие сверху), принять, отказаться, смена статусов.
- **База данных:** `users`, `rides`, `driver_locations`, `bookmarks`, `settings` (см. `lib/data/app_database.dart`).
  Один активный заказ на пассажира и на водителя обеспечивает сама база (уникальные индексы).
  Экраны обновляются сами при изменении базы.

## Что требует интернета

Карта, поиск адресов (Геосаджест), определение адреса (Геокодер) и построение маршрута (OSRM).
Аккаунты, заказы и закладки работают без сети.

## Структура

- `lib/data/app_database.dart` — SQLite: схема и «живые» запросы
- `lib/services/auth_service.dart` — локальные аккаунты (пароль хранится как хеш с солью), вход и выход
- `lib/services/ride_service.dart` — заказы и смена статусов (атомарные UPDATE с проверкой роли)
- `lib/services/driver_location_service.dart` — позиция водителя (пишется в базу, пока он на линии)
- `lib/services/bookmarks_service.dart` — закладки/история/дом/работа
- `lib/services/payment_service.dart` — оплата (заглушка), `lib/services/yandex_api.dart` — карты и маршруты
- `lib/screens/` — вход, регистрация, клиент, водитель; `lib/config.dart` — ключи Яндекса и тариф

## Тариф

Подача 100 ₽ + 20 ₽/км + 5 ₽/мин, минимум 150 ₽, округление до 10 ₽ (`Tariff` в `lib/config.dart`).

## Оплата

Наличные работают. **Картой — заглушка** (`StubPaymentService`): деньги не списываются. Реальный платёжный
провайдер нужно подключать отдельно (реализовать `PaymentService`).

## Ограничения

- Данные лежат только на этом телефоне: удаление приложения или «Очистить данные» удаляет всё.
  Между разными телефонами заказы не передаются.
- Водитель и пассажир не бывают «онлайн» одновременно: при смене аккаунта нужно выйти и войти.
  Положение машины у пассажира — последнее сохранённое положение водителя.
- Позиция водителя обновляется, пока приложение на экране (фоновой службы геолокации нет).
- Заказы в поиске старше 10 минут водителям не показываются.
- Забытый пароль восстановить нельзя (нет сервера); можно зарегистрировать новый аккаунт.

## Сборка APK на GitHub

Workflow `.github/workflows/build-apk.yml` запускается при push в main/master, в pull request и вручную
(Actions → Build APK → Run workflow). Готовый `app-release.apk` лежит в артефактах запуска.
При push тега `v1.0.0` APK прикрепляется к GitHub Release. Сборка идёт на JDK 21, версии Gradle/AGP/Kotlin —
из шаблона Flutter 3.50. APK подписан debug-ключом.
